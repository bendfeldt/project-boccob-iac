# Audit reports (historical)

The files in this folder are **point-in-time reports**. Each one describes both repositories as
they were on its date and at the commits it names. They are kept as evidence of what was checked
and what was found. They are not updated afterwards, so file paths, versions, findings and "open"
items in them may be out of date.

For the current state read the living documentation instead: [overview.md](../overview.md),
[getting-started.md](../getting-started.md), [architecture.md](../architecture.md) and the open
items at the end of [runbook-bootstrap.md](../runbook-bootstrap.md) and
[data-plane.md](../data-plane.md).
